Version 0.1.0
-------------

Features
''''''''

- Add an Earthkit source plugin for MeteoSwiss Open Data.
- Support ICON-CH1-EPS, ICON-CH2-EPS and KENDA-CH1 collections.
- Support exact, interval and latest reference-time requests.
- Select the newest complete run for multiple lead times.
- Return GRIB assets through Earthkit's built-in URL source.
