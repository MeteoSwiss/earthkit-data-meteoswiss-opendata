=========
Changelog
=========

Version 0.2.0
-------------

Features
''''''''

- Add the ``meteoswiss-opendata-constants`` Earthkit source.
- Support horizontal and vertical model constant assets.
- Support ICON-CH1-EPS, ICON-CH2-EPS and KENDA-CH1 constant assets.
- Add usage examples and links to the constants documentation and notebook.
- Add unit tests for constant-asset resolution and plugin discovery.

Version 0.1.0
-------------

Features
''''''''

- Add an Earthkit source plugin for MeteoSwiss Open Data.
- Support ICON-CH1-EPS, ICON-CH2-EPS and KENDA-CH1 collections.
- Support exact, interval and latest reference-time requests.
- Select the newest complete run for multiple lead times.
- Return GRIB assets through Earthkit's built-in URL source.
