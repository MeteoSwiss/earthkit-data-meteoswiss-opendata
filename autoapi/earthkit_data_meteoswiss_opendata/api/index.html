get_asset_urls(request: earthkit_data_meteoswiss_opendata.request.Request) → list[str][source]#

Return assets matching a MeteoSwiss request.

For requests with several lead times, only complete forecast runs are returned.

get_collection_asset_url(collection_id: str, asset_id: str) → str[source]#

Return the URL of a collection-level static asset.

Parameters:

  • collection_id – Fully qualified STAC collection ID.

  • asset_id – Identifier of the collection asset.

Returns:

URL of the requested collection asset.

Raises:

  • requests.HTTPError – If the collection-assets request fails.

  • KeyError – If the requested asset is not present.
